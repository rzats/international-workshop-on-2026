# Converting low-quality library scans into large-print editions

Code, data manifest and manuscript for the SCIA-2026 submission
*Converting low-quality library scans into large-print editions with layout analysis
and constraint-based reflow* (R. Zatserkovnyi, R. Zatserkovna).

Every number in the paper is produced by the scripts here.

## Layout

    paper/international-workshop-on-2026.{odt,docx,pdf}   the manuscript
    paper/figures/                                        figures, regenerated by src/figures.py
    src/                                                  the pipeline
    data/                                                 derived results (raw downloads are gitignored)
    template/                                             the CEURART one-column ODT, unmodified

## Reproducing

    python3 src/fetch.py          # hOCR + Project Gutenberg e-texts for the 14 volumes
    python3 src/parse_hocr.py     # hOCR -> per-page JSONL
    python3 src/lexicon.py        # period lexicon (Webster 1913 + disjoint e-texts)
    python3 src/align.py          # reference transcriptions by anchor alignment
    python3 src/reliability.py    # leave-one-volume-out reliability model
    ./run_pipeline.sh             # the four steps above plus experiments and figures
    python3 src/experiment.py <k> # composition + routing for one volume
    python3 src/aggregate.py      # tables
    python3 src/furniture_eval.py # furniture removal checked against the e-texts
    python3 src/figures.py        # figures
    python3 src/verify_refs.py    # every DOI in the bibliography, against Crossref
    python3 src/paper.py          # build the ODT inside the template, then the PDF

Rendering a real edition needs the page images, which are fetched on demand:

    python3 src/render.py carol 0 0.10        # full large-print edition of one volume
    python3 src/figure_example.py baskerville # the before/after figure

## Corpus

Fourteen public-domain volumes from the Internet Archive, each paired with a clean
Project Gutenberg e-text of the same work (`src/corpus.py`). Raw downloads live under
`data/raw/` and `data/scans/` and are not committed; `src/fetch.py` recreates them.

## Requirements

Python 3.12 with numpy, scipy, scikit-learn, pillow, matplotlib, reportlab, lxml,
requests; LibreOffice for the PDF; the Libertinus and Atkinson Hyperlegible fonts
(`assets/fonts/` holds the latter).
